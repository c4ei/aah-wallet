# IEUM Wallet 0.0.10.6 변경 내역

작성일: 2026-08-05

## 이번 버전에서 완료

- 표시 버전을 `0.0.10.6`, npm/Cargo/Tauri 호환 버전을 `0.0.10-6`으로 올렸다.
- Normal 월렛의 기본 IEUM Core 참조를 `v0.21.7`로 변경했다.
- Windows Normal 빌드에서 체크아웃한 Core Cargo 버전이 정확히 `0.21.7`인지
  검사해 잘못된 태그나 이전 소스가 패키지에 포함되는 것을 차단한다.

## 배포 전제

Chain Actions가 성공한 커밋에 `v0.21.7` 태그가 실제로 올라온 뒤에만 Wallet
Actions를 실행한다. 태그가 없으면 `Checkout IEUM Core` 단계가 실패하는 것이 정상이다.

## 다음 버전 작업

Chain 0.22.0의 암호화된 `node_wallet.keystore`와 입금 조회 RPC가 확정되면 Normal
월렛에서 최초 비밀번호 설정, 백업 확인, 복원, 노드 지갑 잔액과 입금 내역 화면을
연결한다. 키 형식이 확정되기 전에 월렛만 별도로 구현하지 않는다.
