# 보안 안내

## 지키는 원칙

- SEED와 Private Key는 IEUM 노드 RPC에 전송하지 않습니다.
- 디스크에는 Private Key 평문 대신 AES-256-GCM 암호문을 저장합니다.
- 비밀번호 키 파생은 PBKDF2-SHA256 310,000회를 사용합니다.
- 전송할 때 앱 안에서 서명하고 raw transaction만 노드에 보냅니다.
- Rust RPC 프록시는 지갑에 필요한 메서드만 허용합니다.
- `file://`, 사용자/암호가 포함된 RPC URL은 거부합니다.

## 현재 한계

- 사용자가 입력한 비밀번호는 앱이 열린 동안 프로세스 메모리를 거칩니다.
- OS Keychain과 보안 하드웨어는 아직 사용하지 않습니다.
- 루팅·탈옥·악성코드에 감염된 기기는 보호할 수 없습니다.
- 클립보드 자동 삭제, 생체 인증, 피싱 주소 검사는 아직 없습니다.
- 외부 RPC는 HTTPS와 신뢰할 수 있는 운영자를 사용해야 합니다.

## 사용자가 반드시 할 일

1. SEED를 종이 또는 오프라인 금속 백업에 기록합니다.
2. SEED·Private Key를 메신저, 이메일, 클라우드 메모에 올리지 않습니다.
3. 화면 공유와 캡처 중에는 SEED를 열지 않습니다.
4. 먼저 소액 테스트 송금을 합니다.
5. 이 개발 버전에는 실제 가치가 있는 자산을 보관하지 않습니다.
## WebRTC 통화

- WebRTC 미디어는 브라우저가 협상하는 DTLS-SRTP로 보호합니다.
- offer/answer/ICE 신호는 채팅방 AES-256-GCM 키로 암호화합니다.
- `call-audit.jsonl`에는 통화 메타데이터만 저장하고 미디어·SDP·ICE·TURN 인증값은 저장하지 않습니다.
- 신뢰하지 않는 공개 TURN 서버는 통신 메타데이터를 관찰할 수 있으므로 직접 운영하는 TLS TURN과 단기 자격증명을 사용합니다.
## v0.0.7.0 로컬 데이터 보호

- 지갑은 5·15·30분 중 선택한 미사용 시간이 지나면 자동으로 잠깁니다.
- 앱이 백그라운드로 이동하면 즉시 잠기며 미디어 트랙과 복호화 상태를 정리합니다.
- 친구·그룹 주소록은 지갑 비밀값에서 별도로 파생한 AES-256-GCM 키로 암호화합니다.
- 통화 감사 기록은 최근 200건만 화면에서 조회하며 사용자가 기기에서 삭제할 수 있습니다.
