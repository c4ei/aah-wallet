# AAH Wallet v0.0.3.2

## 목표

기존 기능을 일반 사용자도 이해하기 쉽게 만들고, AAH 공식 웹사이트를 지갑 보안 영역과 분리해 제공한다.

## 구현

- 첫 사용 안내와 닉네임 설정
- 선택 이메일 입력과 형식 검사
- 내 주소 복사
- 송금 전 주소·금액·예상 수수료 최종 확인
- `AAH 사이트` 메뉴와 `https://aah.name` 전용 창
- 모바일 메뉴 배치 개선

## 이메일 특이점

현재 프로필은 지갑 주소별 `localStorage`에만 저장한다. 이메일은 로그인·친구 검색·지갑 복구에 사용하지 않으며 서버로 전송하지 않는다. 서버 계정 기능을 만들 때 개인정보 처리, 이메일 인증, 탈퇴·삭제 API를 함께 설계해야 한다.

## AAH 사이트 창 보안

`aah.name`을 지갑의 로컬 React 화면에 iframe으로 넣지 않는다. Rust가 고정된 HTTPS 주소만 별도 Webview 창으로 열며, 해당 창 이름은 Tauri capability의 허용 창 목록에 포함하지 않는다. 따라서 원격 사이트는 지갑 파일 읽기, RPC 호출, 서명 명령 등의 IPC를 호출할 수 없다.

## 쿠팡 광고 연결에 필요한 정보

기존 `aah.name`의 쿠팡 파트너스 링크를 그대로 쓸 수 있다. 다만 저장소에 링크가 없으므로 다음 중 하나가 필요하다.

- 실제 쿠팡 파트너스 추적 URL
- 기존 `aah.name` 소스에서 광고가 들어간 파일 또는 해당 코드
- 배너 이미지와 이동 URL

파트너 비밀번호나 API Secret은 지갑 소스에 넣지 않는다. 쿠팡 영역은 일반 스폰서 링크로만 사용하며 광고 클릭을 4시간 AAH 보상의 완료 조건으로 사용하지 않는다.

## 테스트

```bash
npm install
npm test
npm run build
npm run tauri dev
```

확인 항목:

1. 지갑을 열면 최초 1회 시작 안내가 표시된다.
2. 잘못된 이메일은 저장되지 않는다.
3. 송금 버튼을 누르면 즉시 전송되지 않고 최종 확인 창이 뜬다.
4. `AAH 사이트`에서 버튼을 누르면 별도 창에 `aah.name`이 열린다.
5. 사이트 창을 닫은 뒤 지갑 기능이 계속 동작한다.
