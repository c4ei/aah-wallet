# IEUM Wallet v0.0.9.2 운영 제네시스 연결 수정

## 요청

- IEUM Chain v0.21.4 운영망에 연결할 때 발생하는
  `IEUM 운영망 제네시스와 일치하지 않는 노드입니다.` 오류를 수정한다.

## 원인

월렛은 100 IEUM 테스트 잔액 추가 전의 제네시스 해시를 고정하고 있었다. 체인
v0.21.3은 변경된 제네시스를 반환하므로 Chain ID가 같아도 월렛이 안전하게 연결을
거부했다.

## 처리

- 배포 버전을 `0.0.9.2`, 내부 SemVer를 `0.0.9-2`로 올렸다.
- 운영 제네시스 해시를 다음 값으로 갱신했다.

```text
0x657ce0cfeb8ad38d88a23711ec2664e5e1033aa8ffd5bb648a02ca0f348a9e1a
```

- Chain ID 21004와 위 해시를 단위 테스트에서 함께 고정했다.
