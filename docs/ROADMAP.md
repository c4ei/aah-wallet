# IEUM Wallet 개발 순서

## v0.0.1.x — 기본 지갑 안정화

- 생성·복원·암호화 보관
- 잔액·전송·거래 상태
- 자동 잠금(구현)과 QR 스캔(후속)
- Windows/Ubuntu 패키징

## v0.0.2.x — 4시간 광고 보상

보상 기준:

```text
다음 참여 가능 시각 = 서버가 확정한 마지막 보상 시각 + 4시간
하루 이론상 최대 횟수 = 6회
```

현재 앱에 구현:

- 서버 시각 기준 쿨다운 계산과 표시
- 개발 모드 광고 완료 UI
- 보상 서버 API 계약과 단위 테스트

실제 지급에 필요한 구성:

- 광고 사업자 완료 토큰 검증 서버
- 서버 시간 기준 쿨다운
- 지갑·계정·기기 중복 방지
- 서버가 서명한 보상 청구권
- 재단 보상 지갑의 온체인 지급
- 지급 거래 해시와 실패 재처리

앱 시간이나 지갑 주소만 기준으로 제한하면 시간 조작과 여러 지갑 생성으로 우회할
수 있으므로 서버 검증 없이 출시하지 않습니다.

## v0.0.3.x — 친구와 그룹

- 주소/QR 친구 추가
- 지갑별 로컬 주소록(구현)
- 초대 코드와 그룹 생성
- 그룹 구성원별 순차 송금(구현), 더치페이(후속)
- 개인정보는 체인 밖에 저장하고 최종 송금만 온체인 기록

주소록은 v0.0.7.0부터 지갑 키 기반 AES-256-GCM으로 암호화하며 기존 평문 자료는
잠금 해제 시 자동 이전합니다. 초대 코드를 다른 기기에서 사용하는 서버 동기화는 후속입니다.

## 공개 배포 전

- 체인 RPC와 BFT 실행 루프 완전 결합
- 체크포인트 검증과 장시간 분할망 테스트
- Explorer 인덱서
- 앱·서버·체인 보안 감사
- 개인정보 처리와 광고 보상 정책 검토
