# ieum-wallet v0.0.3.1

## 구현 내용

- 주소와 이름으로 친구 추가
- 동일 주소 중복 등록 방지
- 여러 친구를 선택해 그룹 생성
- 공유 가능한 `IEUM-XXXXXXXXXXXX` 형식의 초대 코드 생성
- 그룹 구성원에게 동일 금액 순차 송금
- PC와 좁은 모바일 화면에 대응하는 탭 UI

## 데이터 보관

친구·그룹 데이터는 현재 지갑 주소별 로컬 앱 저장소에 보관한다. 실제 송금만 체인에 기록한다. 서버 동기화를 추가할 때는 사용자 키로 종단간 암호화한 데이터만 저장해야 한다.

초대 코드는 현재 로컬 그룹을 식별하는 UI용 코드다. 다른 기기에서 코드를 입력해 가입하는 기능은 초대 서버 또는 서명된 초대 문서가 준비된 뒤 활성화한다.

## 그룹 송금 특이점

현재 IEUM Chain에는 원자적 다중 송금이 없다. 앱은 구성원별 nonce를 증가시키면서 거래를 순차 제출한다. 중간에 RPC 오류나 잔액 부족이 발생하면 앞서 접수된 거래는 취소되지 않으므로 일부만 성공할 수 있다.

공개 서비스 전에는 다음 중 하나가 필요하다.

1. 다중 송금 스마트 컨트랙트
2. 체인의 원자적 batch transaction
3. 실패 구성원 재시도 및 거래별 상태 화면

## 테스트 방법

1. 친구 두 명의 테스트넷 주소를 등록한다.
2. 두 친구를 선택해 그룹을 만든다.
3. 초대 코드가 `IEUM-`로 시작하는지 확인한다.
4. 테스트 계정에 수수료를 포함한 잔액을 준비한다.
5. 1명당 소액을 입력해 그룹 송금을 실행한다.
6. 각 거래 해시와 수신 주소 잔액을 노드 RPC에서 확인한다.

```bash
npm test
npm run build
npm run tauri dev
```
