# IEUM Wallet v0.0.7.0

## 요청 및 처리 범위

GitHub에 반영된 v0.0.6.0 다음 버전으로, 공개 배포 전 로컬 보안을 우선 보강했습니다.

- 사용하지 않은 시간이 5·15·30분을 넘으면 지갑 자동 잠금
- 앱이 백그라운드로 이동하면 즉시 잠금
- 잠금 시 진행 중인 통화·미디어 트랙·개인키 메모리 정리
- 친구·그룹 주소록을 지갑 개인키에서 분리 파생한 키로 AES-256-GCM 암호화
- 기존 평문 주소록을 최초 잠금 해제 때 암호화 형식으로 자동 이전
- `call-audit.jsonl` 최근 200건 조회와 사용자 직접 삭제

## 보안 경계

주소록 암호화 키는 PBKDF2-SHA256 310,000회로 지갑 비밀값과 무작위 salt에서
파생하며 저장하지 않습니다. 주소록마다 무작위 96비트 IV를 사용합니다. 지갑이 잠기면
복호화된 주소록과 개인키는 앱 상태에서 제거됩니다.

감사 기록에는 v0.0.6.0과 동일하게 통화 상태 메타데이터만 저장합니다. 음성·영상,
SDP, ICE 후보, TURN 자격증명, 채팅 본문은 조회 화면이나 파일에 저장하지 않습니다.
삭제는 현재 기기의 감사 파일만 제거하며 블록체인 거래에는 영향을 주지 않습니다.

## 호환성과 제외 범위

- 기존 `aah-social-{주소}` 평문 JSON은 같은 저장 키의 암호문으로 교체됩니다.
- 지갑 SEED·개인키를 복원하면 같은 주소록 파일을 다시 열 수 있습니다.
- 앱 저장소 자체를 삭제한 경우 주소록은 SEED만으로 복원되지 않습니다.
- 그룹 화상회의, 통화 녹화, 서버 동기화, QR 카메라 스캔은 포함하지 않았습니다.
