# IEUM Wallet v0.0.8.0

## 처리 내용

- IEUM Chain 기본 RPC와 지갑 기본값을 `http://127.0.0.1:8989`로 통일했습니다.
- 네트워크 상세 설정은 평소 숨기고, 연결 실패 시 `연결 문제` 버튼으로 바로 열 수 있게 했습니다.
- 최근 전송을 기기별 최대 100건 보관하고 5건 단위로 페이징합니다.
- 친구 목록에서 바로 1:1 채팅으로, 그룹 목록에서 바로 그룹 채팅으로 이동합니다.
- 등록된 친구 중 임의의 상대를 고르는 `친구 중 랜덤 대화`를 추가했습니다.

## 랜덤채팅 범위와 추가 작업

이번 버전의 랜덤 대화는 사용자가 직접 등록한 친구 안에서만 상대를 고릅니다. 모르는 사용자끼리 연결하는 공개 랜덤채팅은 중앙 매칭 서비스, 차단·신고, 연령/유해행위 보호, 스팸 제한과 운영 정책이 먼저 필요합니다. 이 안전장치 없이 공개 매칭을 켜지 않습니다.
