# ieum-wallet v0.0.2.1

## 목표

광고 시청 완료를 보상 서버가 검증한 뒤 마지막 확정 시각으로부터 4시간마다 IEUM를 지급한다.

## 이번 소스에 구현된 내용

- 4시간 쿨다운 계산
- PC 시간이 아닌 `serverNow` 기준 남은 시간 계산
- 마지막 확정 시각과 다음 참여 가능 시각 표시
- 지갑 주소별 개발 모드 기록
- 실제 서버 연동 전임을 명확히 표시하는 안전장치
- 관련 단위 테스트

## 실제 지급 전에 필요한 서버 API

### `GET /v1/rewards/status?wallet=0x...`

```json
{
  "serverNow": "2026-07-24T09:00:00Z",
  "lastConfirmedAt": "2026-07-24T05:00:00Z",
  "nextEligibleAt": "2026-07-24T09:00:00Z",
  "dailyConfirmedCount": 2,
  "pendingTxHash": null
}
```

### `POST /v1/rewards/claims`

요청에는 지갑 주소, 광고 사업자의 완료 토큰, 서버 nonce, 지갑 서명을 포함한다. 서버는 완료 토큰 재사용, 4시간 제한, 계정·기기 중복을 검사한 뒤 보상 지갑에서 온체인 송금한다.

## 특이점

- 현재 버튼은 광고 SDK와 보상 서버가 없는 상태에서 UI를 확인하기 위한 개발 모드다.
- 앱의 `localStorage` 기록은 보안 판정에 사용하지 않는다. 삭제하거나 시간을 바꿔도 실제 서버 제한을 우회할 수 없어야 한다.
- 하루 6회 고정 제한 대신 연속 4시간 간격을 기본 정책으로 삼는다. 운영 정책상 일일 상한이 필요하면 서버에서 추가한다.
